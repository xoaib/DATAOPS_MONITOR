DataOps Monitor – Data Pipeline Monitoring & Validation System

A lightweight data engineering support system that simulates basic production pipeline monitoring, data validation, troubleshooting, and incident management.

Features
CSV-based data ingestion
Basic ETL pipeline
Data validation and quality checks
SQL-based source-to-target reconciliation
Pipeline monitoring and logging
First-level troubleshooting
Incident management workflow
ServiceNow-style ticket simulation
Operational reporting
Web dashboard

Skills Demonstrated

SQL, ETL/ELT, data validation, pipeline monitoring, incident management, production support, first-level troubleshooting, operational reporting, REST APIs, and documentation.

Scope

This is an interview-focused project designed to demonstrate junior-level data engineering and production-support concepts. ServiceNow functionality is simulated locally and no real ServiceNow integration is used.
